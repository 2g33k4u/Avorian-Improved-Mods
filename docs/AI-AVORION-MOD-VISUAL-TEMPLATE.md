# [AI] Avorian Improved visual template

Use this standard for every future Avorian Improved Steam Workshop thumbnail so the mods read as one suite.

## Layout

- Square 1:1 composition.
- Small `[AI]` badge in the upper-left.
- One large, centered icon representing the individual mod.
- Bold, high-contrast two-line mod title along the bottom.
- Keep all text and the main icon comfortably inside the edges so it remains readable in Steam's small thumbnail views.

## Visual language

- Deep black/navy starfield backdrop.
- Subtle technical-grid or blueprint frame.
- Cyan/teal illumination for the shared suite identity.
- A restrained amber/yellow accent for focus, selection, or the mod's special function.
- Crisp premium sci-fi game UI/key-art style; avoid clutter, extra slogans, and fake interface statistics.

## Per-mod changes

Keep the layout, `[AI]` badge, background treatment, and core palette consistent. Change only the centered icon, the title, and—when useful—the small amber accent treatment to match the mod's purpose.

## Workshop delivery

- Save the selected image as `thumb.png` in the mod folder.
- Keep it under 1 MB.
- Do not use a generic Steam placeholder.

The approved reference for this standard is the `[AI] Turret Dynamics` thumbnail concept generated on 2026-07-19.
